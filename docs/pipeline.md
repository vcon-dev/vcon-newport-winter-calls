# Pipeline contract

The scripts share these file formats. Change a format here first.

```
config/corpus.yaml              frozen design constants
config/eleanor-pucci.json       hand-written transcript (same shape as build/transcripts/*.json)
config/prompts/generate.md      system prompt for transcript generation
config/prompts/verify.md        system prompt for blind verification
scripts/plan_corpus.py          corpus.yaml -> build/specs.jsonl + truth/manifest.json
scripts/generate.py             specs -> Message Batches -> build/transcripts/<uuid>.json
scripts/build_vcons.py          specs + transcripts -> vcons/*.vcon.json
scripts/lint.py                 deterministic checks over vcons/ + manifest
scripts/verify.py               blind Claude read of every vCon -> build/verify/ + report
```

`build/` is gitignored scratch. `truth/` and `vcons/` are committed.

```json

  "uuid": "uuid v8 string, deterministic from seed + index",
  "index": 0,
  "start": "2026-02-24T09:14:00-05:00",
  "duration_s": 420,
  "department": "public-works",
  "topic": "storm-drain-flooding",
  "tone": "frustrated",
  "channel": "landline | cell | cell-poor | speakerphone",
  "caller": {"name": "Eleanor Pucci", "age_band": "60s", "speech": "short sentences, local idiom, no small talk", "household_role": "owner"},
  "clerk": {"name": "Denise Arruda", "style": "brisk and kind"},
  "address": {"id": "a03", "number": 701, "street": "Thames Street", "neighborhood": "Fifth Ward"},
  "storm": {"id": "s5", "name": "late-February nor'easter", "days_after_end": 2},
  "planted": {
    "cluster": true,
    "repeat_flood_second": true,
    "lawyer": false,
    "card_full": {"number": "4111 1111 1111 1111", "amount_usd": 90},
    "after_hours_pay": false,
    "fence_permit": false,
    "downed_tree_where": false
  },
  "decoys": ["attorney_benign" | "card_partial" | "cluster_street_other_topic" | "flooding_elsewhere" | ...],
  "beats": ["plain-language story points the transcript must contain"],
  "must_not": ["words or moves the transcript must avoid, e.g. the word lawyer"],

```

`address` is null when the caller never gives one. `storm` is null outside storm windows.

## build/transcripts/<uuid>.json

```json
{"uuid": "...", "turns": [{"speaker": "clerk", "text": "Public Works, this is Denise."}, {"speaker": "caller", "text": "..."}]}
```

Noise markers allowed inside text: `[inaudible]`, `[crosstalk]`, `[line breaks up]`, `[pause]`.

## vCon shape (vcon-core-04, `vcon: "0.4.0"`)

- `uuid` from the spec; `created_at` = call end; `subject` = `"Inbound call, <Department Name>"` (never the topic).
- `parties`: `[0]` caller `{name, role: "resident", validation: "synthetic"}`, `[1]` clerk `{name, role: "clerk", validation: "synthetic"}`. No phone numbers, no civic address.
- `dialog`: one `type: "text"` entry per turn: `start` (ISO with offset), `duration` (seconds, turns sum to the call duration), `parties: [speaker_idx]`, `originator: speaker_idx`, `mediatype: "text/plain"`, `encoding: "none"`, `body`.
- `attachments` (all `party: 0, dialog: 0, start: <call start>, mediatype: "application/json", encoding: "json"`, raw JSON body):
  - `purpose: "tags"`, body `{"department": "<department>"}`. Nothing else.
  - `purpose: "call_detail"`, body `{"direction": "inbound", "start", "end", "duration_seconds", "channel"}`.
  - `purpose: "lawful_basis"`, body `{"lawful_basis": "legitimate_interests", "expiration": null, "purpose_grants": [recording, transcription, analysis, redistribution all granted at the call start], "proof_mechanisms": [{"mechanism_type": "external_system", "description": "Synthetic corpus generated by vcon-dev/vcon-newport-winter-calls; no real data subject"}]}`.
- `extensions: ["lawful_basis"]`. No `analysis` array.
- Filename: `vcons/<YYYY-MM-DD>-<HHMM>-<department>-<first 8 hex of uuid>.vcon.json`.
